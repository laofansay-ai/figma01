🔧 Supabase RLS 策略修复指南

⚠️ 问题说明

你遇到的错误 "new row violates row-level security policy for table 'orders'" 是因为 orders 和 order_items 表缺少 INSERT 权限的 RLS 策略。

📝 第一步：复制 SQL 修复脚本

-- 修复 orders 表的 RLS 策略 CREATE POLICY "Users can create own orders" ON orders FOR INSERT WITH CHECK (auth.uid() = user_id); -- 修复 order_items 表的 RLS 策略 CREATE POLICY "Users can create order items for own orders" ON order_items FOR INSERT WITH CHECK ( EXISTS ( SELECT 1 FROM orders WHERE orders.id = order_items.order_id AND orders.user_id = auth.uid() ) );

🌐 第二步：在 Supabase Dashboard 中执行

  1. 打开 Supabase Dashboard
  2. 选择你的项目：gkzsushdwnmhcpiwcwip
  3. 在左侧菜单点击 "SQL Editor"
  4. 粘贴上面复制的 SQL 脚本
  5. 点击 "Run" 按钮执行

✅ 第三步：验证修复结果

执行完成后，你应该看到类似这样的成功消息：

现在你可以重新测试订单创建功能了！
