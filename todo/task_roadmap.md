## 技术栈总结

### 前端技术

- **框架**: React 18 + TypeScript
- **样式**: Tailwind CSS + Headless UI
- **路由**: React Router v6
- **状态管理**: Context API + React Query
- **构建工具**: Vite
- **图标**: Lucide React

### 后端技术

- **数据库**: PostgreSQL (Supabase)
- **认证**: Supabase Auth
- **API**: Supabase REST API + Edge Functions
- **文件存储**: Supabase Storage
- **实时功能**: Supabase Realtime

### 第三方服务

- **支付**: Stripe
- **图片**: Pexels API
- **邮件**: Supabase + SendGrid
- **分析**: Google Analytics
- **监控**: Sentry
- **部署**: Vercel/Netlify
