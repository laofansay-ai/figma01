## 🛠 技术实现

### 前端技术栈

- **核心框架**: React 18.2.0
- **构建工具**: Vite 6.3.5
- **样式系统**: Tailwind CSS 4.1.7
- **UI 组件**: shadcn/ui + Radix UI
- **路由管理**: React Router DOM 7.6.1
- **状态管理**: Context API
- **动画库**: Framer Motion 12.15.0
- **图标库**: Lucide React 0.510.0

### 后端技术栈

- **数据库**: Supabase (PostgreSQL)
- **认证系统**: Supabase Auth
- **文件存储**: Supabase Storage
- **API**: RESTful + GraphQL

### 开发工具

- **包管理器**: pnpm 10.4.1
- **代码检查**: ESLint 9.25.0
- **版本控制**: Git + GitHub

## 💾 数据库架构

### 完整的数据表设计 (11 个核心表)

1. **profiles** - 用户资料信息
2. **categories** - 商品分类层级
3. **products** - 商品详细信息
4. **product_reviews** - 商品评价和评分
5. **cart_items** - 购物车商品
6. **orders** - 订单主信息
7. **order_items** - 订单商品明细
8. **user_addresses** - 用户地址管理
9. **wishlists** - 用户愿望清单
10. **coupons** - 优惠券系统
11. **site_settings** - 网站设置

### 数据库特性

- ✅ **行级安全 (RLS)**: 确保数据访问安全

- ✅ **索引优化**: 提升查询性能
- ✅ **触发器**: 自动维护数据状态
- ✅ **默认数据**: 预置分类和设置
